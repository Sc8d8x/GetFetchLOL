GetFetchLOL - Cross-Platform System information Tool

A lightweight, fast system information fetcher written in C++ that displays hardware specs, OS details, and system statistics in a clean, colorful terminal output.

- Cross-Platforms support (Mac, Linux, Windows)
- Colorful, customizable output
- No external dependencies
- Detects CPU, RAM, GPU, OS, uptime, and more

Tech Stack
- Language: C++/C
- Build System: CMake


Quick Start

git clone https://github.com/Sc8d8x/GetFetchLOL

if used Cmake
- cd getfetchlol
- mkdir build && cd build
- cmake ..
- cmake --build .
- ./getfetchlol
